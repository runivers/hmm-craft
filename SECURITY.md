# Security policy

Only the latest release of hmm-craft is supported.

Report a vulnerability privately, through the "Report a vulnerability" button
on the repository's Security tab, and not in a public issue. If that button is
missing, write to `<project address>`.

There is no response time: the project has one maintainer, who reads reports as
time allows. A report with a short example that reproduces the problem is
looked at first.
